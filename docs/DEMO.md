# 5 分钟演示脚本

> 演示用。全程**演示模式**（用 `node runtests.js` 起测试服务最省事：端口 8541、独立测试库、零 API 费用、结果可复现）。
> 演示前确认页面顶栏有余额、左侧导航可见。

## 0:00–0:40 · 一句话讲清它是什么

> "这不是一个调大模型 API 的脚本，是一条带成本预估、预算护栏、知识点驱动、多模型互检和人工审批的制题流水线。
> 要解决的问题是：**怎么敢把给付费客户出题这件事交给 AI 跑**——你得知道钱花在哪、错题被谁拦下、出问题怎么查。"

指着左侧导航过一遍：对话制题 / 我的资料库 / 制题任务 / 我的题库 / 个人中心
（管理员的 用户管理 / 审计与撤回 / API 池 / 金标集评估 / 经验库 / 模型与预算）。

## 0:40–1:40 · 资料 → 知识点（本版本核心变化）

1. 点「对话制题」→ 资料选择里选一份资料库中的资料（没有资料也可以在第 2 张卡片直接上传 PDF/Word）。
2. 点 **🤖 让 AI 先分析知识点**，等 2 秒，指着知识点面板：

   > "出题前先让 AI 通读资料，把**考点清单**列出来：每个知识点带章节、考查方式和重要性。
   > 这一步解决的是老问题——用户说'按知识点分别出题'，模型原来听不懂。现在知识点是**结构化落库**的，
   > 出题时按考点从资料里取材，跑完还能检查覆盖率。"

3. 取消勾选两个不想考的知识点，把"每个知识点各出"设为 `2` 道，点 **生成需求**（一句话都不用写）。

4. 点 **🧮 解析需求并估算费用**。指着需求表：

   > "12 个知识点 × 2 道 = 24 题的逐条需求，每条都挂着具体考点。"

## 1:40–2:20 · 报价单（强调"接单前先算钱"）

指着报价单：

> "按**资料规模 × 题量 × 质检家数 × 识图张数**估算 token 和费用，按成本加成出报价，可直接复制发客户。
> 注意出题这一行：资料是按考点**检索注入**的（每批约 8000 字预算），不是把整份资料重复塞进去——
> 所以报价和实际用量对得上，也不会出现'报价按全本算、出的题只覆盖第一章'。"

> "**人工闸门**：不批准报价，Agent 一步都不会跑。它管钱，你管决策。"

## 2:20–3:20 · 跑流水线，看知识点覆盖

1. 点 **✓ 确认费用，开始制题**，自动进入任务详情，盯着日志区滚动
   （出题日志会写"取材块 3,7,11"——这是资料按考点取段的证据）。

2. 跑完指着统计卡片与顶部成本：

   > "24 题：16 题两家质检员独立重解答案一致，**自动入库**；8 题分歧进人工队列。
   > 顶部'成本 ¥0.184（已入账 ¥0.184）'——**流水线一停下就按实际用量结算**，账单表逐笔可查，重跑也不会重复扣。"

3. 若有知识点没出到题，页面会出黄条列出"哪些知识点还没有出到题"：

   > "这就是覆盖率检查，避免客户拿到的题库缺章少节。"

## 3:20–4:00 · 分歧进人工（全场重点）

滚到「⚠ 待人工审核」，展开一道分歧题：

> "出题答案 B，质检员A 独立重解也是 B，质检员B 算出来是 C。**两家不同厂商的模型独立解题产生分歧**，
> 这就是我需要的错误探测器——单模型自检发现不了自己的系统性错误，异构模型的分歧才是真信号。"

演示三个动作：

- **✓ 采纳** → 统计里"人工采纳"+1。
- **✎ 修改后采纳** → 展开编辑区改一处 → "改完的内容会**写进经验库**（连改了哪个字段、正确答案是什么一起记），
  下次同类考点出题时按相关度检索注入，Agent 不在同一个坑里摔两次。"
- **↻ 打回重新生成** → "补一道新题走完整流水线，预算自动小额追加，不会卡死。"

## 4:00–4:40 · 审计与撤回（管理端，本次新增）

1. 点「🛡 审计与撤回」：

   > "普通用户在个人中心只看得到**自己的**操作；配置、供应商、授权这些管理动作只在这里。
   > 每个账号有唯一用户号（管理员 admin1 起、用户 u1 起），按用户号一查就是全部操作记录，也能导出 CSV。"

2. 指着「待处理的撤回申请」：

   > "用户做错了事（误删资料、手滑隐藏题目）在个人中心点'申请撤回'，我这里看到理由，一键批准——
   > 撤销不是删日志，而是**写一条反向的补偿操作**：误充的钱扣回、隐藏的题恢复推送、
   > 审核过的题退回待审、删掉的资料恢复（所以删除改成了软删除）。
   > 原记录标'已撤回'并留一条指向它的审计痕迹，谁在什么时候撤销了谁的操作永远查得到。"

## 4:40–5:00 · 题库与个人中心 + 收尾

1. 点「我的题库」：

   > "制完题立刻可刷：按**制题批次**分组（每次制题的要求不同，不会杂糅在一起），错题自动进错题本并优先推送，
   > 选择题支持键盘 1-4 作答，AI 讲解可连续追问。"

2. 点「个人中心」：

   > "签到、累计在线时长、账务流水（每笔扣费/充值/退回）、登录设备可一键踢下线，操作记录里能直接申请撤回。"

3. 收尾：

   > "从资料到可交付题库，每一步都有成本、有留痕、有质检、有人工闸门，出问题能定位、能续跑、能撤回。
   > 这就是'敢交给 AI 跑'的意思。"

## 演示要点备忘（自己看，不讲给观众）

| 想传达的印象 | 靠哪个动作体现 |
|---|---|
| 懂业务痛点 | "按知识点分别出题"这类说法能被正确展开 |
| 成本可控 | 报价单逐岗位明细 + 预算硬闸 + 账单流水 + 幂等 |
| 有人工闸门 | 必须点"批准"才启动；分歧题必须人裁决 |
| 技术判断力 | 实测 OCR 读不出树形图 → 视觉模型做语义描述；分块检索取代截断（有标定/实测） |
| 质量不是自说自话 | 两家质检员的判定对比 + 知识点覆盖率 |
| 会学习 | 修改后采纳 → 经验库（结构化，按相关度检索注入） |
| 工程可靠 | 幂等续跑 / 重启后可恢复 / 事件日志 / 结构化日志 / 健康检查 / 优雅停机 |
| 敢管责任 | 用户与管理员操作分离 + 按用户号审计 + 一键撤回（写补偿而非删日志） |
| 可交付 | Docker / CI / 版本化数据库迁移 / 8 个测试套件全绿 |
